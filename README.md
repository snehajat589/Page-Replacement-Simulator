# Page Replacement Simulator

## About the Project
This project simulates three Operating System page replacement algorithms: FIFO (First In First Out), LRU (Least Recently Used), and Optimal Page Replacement.

## Features
- Accepts a page reference string and number of frames
- Simulates FIFO, LRU, and Optimal algorithms
- Displays page hits and page faults
- Calculates hit ratio and fault ratio
- Compares algorithm performance

## Technologies Used
- Python
- Google Colab
- Jupyter Notebook

## Purpose
Created as part of an Operating Systems Lab assignment to understand and compare page replacement algorithms.
